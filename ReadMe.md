# LARS - Learner Academic Records System

## What is LARS?

LARS (Learner Academic Records System) is Zambia's central database for all graduate records. It's owned by **ZAQA (Zambia Qualifications Authority)** and developed by **amcodecase**.

## Purpose

LARS serves as the single source of truth for academic qualifications from three main educational sectors in Zambia:

- **HE** - Higher Education institutions (Universities)
- **TEVETA** - Technical and vocational training colleges
- **ECZ** - Examinations Council of Zambia

## Key Features

- **Centralized Records** - All graduate data in one secure location
- **Multi-Institution Support** - Connects universities, colleges, and examination centers
- **Qualification Verification** - Employers and institutions can verify credentials
- **Secure Access** - Role-based permissions and data protection
- **Standardized Format** - Consistent record structure across all institutions

## How It Works

```
Educational Institutions → LARS Database → Verification Services
(HE, TEVETA, ECZ)         (Central Hub)    (Employers, Others)
```

## Who Uses LARS?

- **ZAQA** - Primary users for managing and monitoring all qualifications
- **Institution Representatives** - Designated staff who upload student records for their institutions
- **Educational Institutions** - Through their appointed representatives
- **Government** - Access skills and education data
- **Students** - Access their academic records

## Technology

- **Database**: MySQL
- **Backend**: PHP
- **Security**: Encrypted data with secure authentication
- **Access**: Web portal interface

## Getting Started

### For Institutions
1. Contact ZAQA for institution registration
2. Designate an institution representative
3. Representative receives login credentials
4. Upload graduate records through web portal

### For ZAQA Users
1. Receive system credentials from administrator
2. Access web portal to manage records
3. Monitor and verify qualifications
